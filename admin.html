Conecte ao seu repositório do GitHub para editar e publicar o conteúdo.

Como criar o token (uma vez só)
  1. No GitHub, vá em Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Em Repository access, escolha Only select repositories e marque só o repositório deste site.
  3. Em Permissions → Repository permissions → Contents, escolha Read and write.
  4. Gere o token, copie e cole aqui. Ele fica salvo apenas neste navegador.
